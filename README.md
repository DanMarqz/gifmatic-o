# gifmatic-o

This is an application to obtain gif in a simple way, it was made with React, Vite and Typescript.

The purpose of this project is to show the knowledge and mastery of:

- Custom Hooks
- APIs consumption
- Communication between components
- Emission of an event to the parent.

This project was made to learn and practice React, Vite and Typescript. 

Whenever I start a new project, I don't know what to write for the first commit. After doing a “git init” there is technically nothing there...

## Install

```npm
yarn install
```

# Usage

To run the project: 

```npm
yarn run dev
```
